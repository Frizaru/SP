# TXC SYSTEM — Программа для управления базой с пилотами

* [C++ Version](https://img.shields.io/badge/C++-17-blue.svg)
* [License](https://img.shields.io/badge/License-MIT-green.svg)
* [Status](https://img.shields.io/badge/Status-Stable-brightgreen.svg)

Это базовая модель, созданная, как первый проект, для понимания основ баз данных и работы с ними.


## Возможности
1. **CRUD операции** — добавление, чтение, обновление и удаление данных. Обеспечение программы полным жизненным циклом
2. **Валидация входных данных** — все входные данные строго проверяются, чтобы избегать "обвалов" программы.
3. **Система логов** — каждое дейсвтие отслеживается и хранится в отедльном файле.
4. **Интерактивное меню** — интуитивно понятный интерфейс в консоли.
5. **Обработка ошибок** — грамотная обработка исключений.

## Установка и запуск

### Требования
- КОМПИЛЯТОР С++17 (g++, clang)

### Быстрый старт
1. Клонирование репозитория 
```
git clone https://github.com/ваш-логин/txc-system.git
cd txc-system
```
2. Компиляция
```
g++ -std=c++17 a.cpp -o a.exe
```
3. Запуск
```
./a.exe
```

## Как использовать?

### Главное меню
```
WELCOME TO TXC SYSTEM
1. Вывести список пилотов
2. Добавить пилота
3. Удалить пилота
4.Выход
```
### Пример работы
```
$ ./a.exe
Введите имя: 
Егор
Система приветствует, Егор! Инициализация протокола 'СП ТХС'
```

### Ключевые функции
- **validate()** — валидация имени пилота
- **logEvent()** - система логов с временными метками
- **input_pilots()** - ввод имени пилота (циклична)
- **check_duplicates()** - проверка всей базы имен на наличие вводящегося имени

### Логирование
Система выводит любое действие, выполненное программой, с точной временной меткой
```
[Thu Jan 29 16:07:54 2026][INFO] Введен ID пилота для удаления
[Thu Jan 29 16:07:57 2026][ERROR] Было введено некорректное значение в поле для ID удаляемого пилота!
[Thu Jan 29 16:07:57 2026][INFO] Введен ID пилота для удаления

```

### Тестирование
В ходе работы программы всегда проверяются следующие сценарие:
- **Проверка на дупликаты** 
- **Валидация имен пилотов**
- **Безопасное удаление пилотов**
